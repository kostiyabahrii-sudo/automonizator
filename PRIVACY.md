# Політика конфіденційності

Цей застосунок ("Pinterest Auto-Poster") — приватний інструмент для
автоматизації публікації власного контенту одного користувача на його
особистому обліковому записі Pinterest. Він не є публічним сервісом і не
надається третім особам.

## Які дані використовуються

- **Access/refresh token Pinterest OAuth** — використовується виключно
  для звернень до офіційного Pinterest API v5 від імені власника
  облікового запису (публікація пінів на його ж дошку). Зберігається
  локально на пристрої користувача (`.env`, `state/state.json`) і нікуди
  більше не передається.
- **Зображення та тексти постів** — беруться з локальної папки
  користувача (`posts/pending/`) і надсилаються лише до Pinterest API
  для створення піна.

## Що НЕ відбувається

- Дані не передаються жодним третім сторонам, рекламним мережам чи
  аналітичним сервісам.
- Застосунок не збирає дані інших користувачів Pinterest, не читає їхні
  профілі, не взаємодіє з чужими акаунтами.
- Немає серверної частини — код виконується локально на пристрої
  власника акаунта.

## Зберігання та видалення даних

Усі дані (токени, стан, логи) зберігаються локально у файлах репозиторію
власника. Щоб видалити всі дані — достатньо видалити файли `.env`,
`config.yaml`, `state/state.json` та вміст `logs/`, а також відкликати
доступ застосунку в налаштуваннях Pinterest
(Settings → Apps → Remove access).
